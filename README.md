# HospitalOS

Aplicación desarrollada en Java enfocada en la gestión operativa de un entorno hospitalario mediante la implementación manual de estructuras de datos lineales y dinámicas.

## Estructura del Proyecto (`edu.codigo.compensar`)

* **`Principal.java`**: Punto de entrada de la aplicación y control del flujo de interacción con el usuario.
* **`HospitalOS.java` y `Hospital.java`**: Núcleo lógico encargado de administrar los registros y operaciones generales del centro médico.
* **`PilaTratamientos.java`**: Implementación de una pila (LIFO) para registrar y consultar el historial de tratamientos aplicados.
* **`Nodo.java` y `NodoTratamiento.java`**: Unidades base de almacenamiento en memoria dinámica con enlaces entre registros.

## Tecnologías y Ejecución

* **Lenguaje:** Java (JDK 8 o superior)
* **IDE:** Apache NetBeans

Para ejecutarlo, clona el repositorio, abre la carpeta del proyecto desde NetBeans y ejecuta la clase `Principal.java`.
